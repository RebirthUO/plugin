# Player Skill Workflow

Read this reference when an action has a target, delay, gain, or retained
effect. Confirm current APIs and state owners in the consuming checkout.

| Surface | Establish before editing |
|---|---|
| Entry | Active-use command, passive hook, and eligibility checks |
| Delay | Owner, start point, retry behavior, cancellation, and restoration |
| Target | Selection and resolution-time validity |
| Mutation | Gain/effect owner, duplicate prevention, and visible feedback |
| Exit | Interrupt, deletion, disconnect, and post-load behavior |

Use independent evidence for player-facing formulas and requirements. Source
inspection can establish implementation state, not production mechanics.
