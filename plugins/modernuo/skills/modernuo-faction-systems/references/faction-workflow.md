# Faction Workflow

Read this reference for membership, town, election, guard, or faction-item
changes. Confirm current types and state ownership in the consuming checkout.

| Surface | Establish before editing |
|---|---|
| Membership | Eligibility, join/leave transition, and conflict handling |
| Authority | Rank, election, town, staff, and stale-response checks |
| World state | Controller/item/mobile owner and removal path |
| Economy | Currency/reward source, recipient, and duplicate prevention |
| Time | Timer owner, cancellation, offline behavior, and restoration |

Do not use a UI response as proof of current authorization. Revalidate the
player and authoritative state at the mutation point.
