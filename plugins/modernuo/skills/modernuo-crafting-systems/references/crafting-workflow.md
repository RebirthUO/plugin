# Crafting Workflow

Read this reference when recipe registration, resources, quality, or repair is
in scope. Confirm all symbols against the consuming checkout.

| Step | Required proof |
|---|---|
| Entry | Tool, user, and recipe eligibility |
| Inputs | Resource alternatives, quantities, and consumption timing |
| Resolution | Success/failure, quality, exceptional effects, and maker identity |
| Output | Recipient, placement/capacity handling, and persistence |
| Recovery | No partial loss, duplicate output, or stale context on rejection |

For a bulk-order connection, separately identify offer, validation, credit, and
reward ownership. Do not let local implementation data establish player-facing
rates, requirements, or rewards.
